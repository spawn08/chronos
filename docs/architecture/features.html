Capabilities

Feature Catalog

What Chronos gives you out of the box, grouped by the layer that owns it. Every feature is backed by an interface, so it is extensible and testable.

Agents & Orchestration sdk/

Fluent agent builder

Compose an agent with model, tools, memory, knowledge, guardrails, and hooks via a chained builder, then Build().

sdk/agent

Multi-agent teams

Sequential, parallel, router, and coordinator strategies, plus swarm/hierarchy patterns over a back-pressured message bus.

sdk/team

Memory

Short-term conversation buffer and long-term memories injected into context; an LLM manager extracts memories from a conversation.

sdk/memory

Knowledge / RAG

Load documents, embed them, and retrieve top-k passages into the prompt automatically on each chat turn.

sdk/knowledge

Skills

Versioned, registrable capability packages with metadata manifests.

sdk/skill

Output schemas

Constrain responses to a JSON Schema and validate the model output against it before returning.

sdk/agent

Durable Runtime engine/

StateGraph

Model work as a graph of nodes and edges. Every step checkpoints, so runs resume after a crash and survive process restarts.

engine/graph

Human-in-the-loop

Interrupt nodes pause a run for approval; the run is persisted and resumed once a decision is recorded.

engine/graph + os/approval

Durable queue

Leased workers with heartbeats, durable sleep, park/signal, orphan recovery, idempotency keys, and a reliable outbox.

engine/queue

Model providers

Unified Chat/StreamChat across OpenAI, Anthropic, Gemini, Azure, Vertex, Bedrock, Mistral, Ollama, and any OpenAI-compatible endpoint.

engine/model

Tools

Registry with JSON-Schema parameters, per-tool permissions, and approval gating for sensitive calls.

engine/tool

Hooks

Composable middleware: retry, rate-limit, cache, cost tracking, and metrics around every model and tool call.

engine/hooks

Guardrails

Input and output validation with a simple Check(ctx, content) Result contract.

engine/guardrails

MCP client

Import tools and resources from Model Context Protocol servers over stdio (subprocess) or HTTP+SSE (remote).

engine/mcp

Streaming

A pub/sub broker fans graph and node events out to SSE subscribers, scoped per session topic.

engine/stream

Control Plane os/

HTTP API

Sessions, session state, traces, event stream, approvals, schedules, health, and Prometheus metrics endpoints.

os/server.go

Auth & RBAC

Pluggable auth middleware derives the tenant from the authenticated principal — never from client-supplied ids.

os/auth

Tracing & audit

A span collector records graph and node spans and an append-only audit log, persisted through Storage.

os/trace

Approval service

Lists pending approvals and records decisions that unblock paused human-in-the-loop runs.

os/approval

Scheduler

Cron-style triggers to launch runs on a schedule.

os/scheduler

Chat interfaces

Slack, Discord, and Telegram front-ends plus a webhook receiver.

os/interfaces

Safe Execution sandbox/

Process

Subprocess with a timeout and its own process group, so a timeout reaps the whole tree.

no deps

Container

Docker with a hardened profile: non-root, caps dropped, seccomp, read-only rootfs, pids/ulimits; optional gVisor/Kata runtime; warm pool.

Docker

WASM (WASI)

Pure-Go wazero runtime. Memory-safe linear-memory isolation, no host access unless granted.

wazero

Kubernetes Job

One-shot hardened Job per execution; collects logs + exit code, then deletes the Job.

client-go

Persistence storage/

Two interfaces, fourteen adapters. See Internals → Storage adapters for the full matrix.

Relational

SQLite (pure-Go driver) for dev/test; PostgreSQL for production, with pagination, retention, and batch ingestion.

NoSQL

MongoDB, DynamoDB (AWS SDK v2), and Redis — all implementing the full Storage interface.

Vector stores

Qdrant, pgvector, Pinecone, Weaviate, Milvus, Redis-vector, Chroma, and LanceDB behind VectorStore.

Evaluation & Ops

Eval suites

Score agents with accuracy, performance, and reliability evals — declared in YAML or Go, runnable from the CLI with a CI-gating exit code.

evals/

CLI

Interactive REPL and headless commands: serve, run, pipe, agent, team, sessions, memory, db, eval, deploy, monitor.

cli/

Deploy

Helm chart with Deployment, Service, Ingress, HPA, Secret/ExternalSecret, PDB, and ServiceMonitor.

deploy/helm
