Architecture Guide

Chronos — Durable, Scalable AI Agents in Go

Chronos is a Go framework for building agentic systems that survive restarts, scale horizontally, and stay observable. It is organised as four cooperating layers — a control plane, a durable runtime, a user-facing SDK, and pluggable storage.

The Four Layers

Each layer depends only on the layer below it through interfaces. You can swap any implementation — storage backend, model provider, sandbox — without touching the layers above.

Design Principles

Durable by default

Every graph step writes a checkpoint and an ordered event to the ledger in one transaction, so a run resumes exactly where it stopped after a crash.

Interface segregation

Relational Storage is separate from VectorStore; providers, guardrails, hooks, and sandboxes are all small interfaces you can implement.

Adapter everywhere

Backends are chosen by config and swapped without code changes — SQLite in dev, Postgres in prod, any of five vector stores for RAG.

Safe execution

Untrusted tool/skill code runs behind the Sandbox interface with hardened container, WASM, and Kubernetes Job backends.

Observable

The runner emits stream events and opens trace spans around the graph and every node; the control plane exposes them over SSE and Prometheus.

Multi-tenant

Tenant identity is carried in context, stamped on every write, and enforced on reads — cross-tenant id lookups resolve to not-found.
