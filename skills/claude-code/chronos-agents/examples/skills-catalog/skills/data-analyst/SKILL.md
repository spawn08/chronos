# Data Analysis Skill

## When to use
Activate this skill when:
- Analyzing CSV, JSON, or tabular data
- Identifying trends, outliers, or patterns
- Producing data-driven reports or recommendations

## Approach
1. **Understand the data**: Read headers, sample rows, check types
2. **Clean**: Identify missing values, duplicates, inconsistencies
3. **Analyze**: Compute aggregates, correlations, distributions
4. **Interpret**: What do the numbers mean in business context?
5. **Report**: Present findings with supporting data points

## Output format
- **Summary**: 2-3 sentence overview of key findings
- **Metrics**: Table of key statistics
- **Insights**: Bulleted list with data-backed observations
- **Recommendations**: Actionable next steps based on the analysis
